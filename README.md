# urlandipre.com — clone estático

Clone do site original (Hostinger Website Builder), em HTML/CSS estático.

- Abra `index.html` direto no navegador, ou sirva a pasta: `python3 -m http.server`
- Páginas PT na raiz, EN em `en/`
- `assets/css` estilos · `assets/fonts` fontes · `assets/img` imagens · `assets/js/site.js` interações
- `site.js` recria: animação de entrada ao rolar, menu mobile, seletor PT/EN, altura dos divisores e o formulário de contato (abre o e-mail via `mailto:`)
